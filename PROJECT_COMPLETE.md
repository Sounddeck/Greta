## Integration Architecture

### Service Integration Matrix

| Service | Integrates With | Integration Type |
|---------|----------------|------------------|
| LLM | All services | Core inference |
| Model | LLM, LoRA | Model management |
| AutoGen | LLM, RAG, Tools | Multi-agent |
| Conversation | LLM, AutoGen | Message storage |
| RAG | LLM, AutoGen | Knowledge retrieval |
| LoRA | LLM, Model | Fine-tuning |
| Templates | AutoGen | Agent creation |
| Context | All services | Context management |
| Portability | All services | Data export/import |
| MCP | All services | Tool exposure |
| Hook | All services | Event hooks |
| Voice | All services | Voice interface |

### Event Flow
1. **Voice Input** → Voice Service (STT)
2. **Command Parsing** → Hook System (pre-hooks)
3. **Service Routing** → MCP Service
4. **Agent Execution** → AutoGen Service
5. **Knowledge Retrieval** → RAG Service
6. **LLM Inference** → LLM Service
7. **Context Management** → Context Service
8. **Response Generation** → Hook System (post-hooks)
9. **Voice Output** → Voice Service (TTS)
10. **Data Persistence** → Conversation/Portability Services
